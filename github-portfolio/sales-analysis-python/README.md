# Sales Analysis (Python)

A small command-line tool that analyzes sales data of an online shop and prints a business report.

## What it does
- Calculates total revenue, number of orders and average order value
- Shows revenue by month and by product category
- Lists the top 3 products by revenue

## How to run
```bash
python analyze.py
```
Requires Python 3.8+. No external libraries needed.

## Files
- `analyze.py` - the analysis script
- `sales.csv` - sample data (order id, date, product, category, quantity, price)
